Kamus Block Scratch

Kenali setiap block, lalu bikin game sendiri.

Klik block mana saja untuk melihat fungsi, cara pakai, contoh susunan, dan preview singkatnya.

Pilih satu block di sebelah untuk melihat penjelasannya.

Tutorial membuat game

Pilih cara belajarmu. Mode Ikuti Langkah menampilkan susunan block lengkap. Mode Mahir hanya memberi tantangan dan kamu boleh mengintip jawabannya kalau buntu.

Mode Bebas

Sudah bisa dasar-dasarnya? Bagian pertama berisi lima komponen wajib agar game apa pun bisa dimainkan. Bagian kedua berisi fitur tambahan yang boleh kamu pilih sesukamu. Semua dirakit sendiri di Scratch.

Kebutuhan minimal sebuah game

Siapkan dulu: 2 sprite (pemain dan benda yang bergerak), 2 variabel untuk semua sprite (Skor dan Nyawa), dan backdrop bebas. Lalu centang kelima komponen wajib di bawah setelah kamu membuatnya.

Komponen wajib

Fitur tambahan (opsional)

Tips: mulai dari satu fitur kecil, tes, baru tambah fitur berikutnya. Game besar selalu dibangun dari potongan kecil.

Buku referensi

Computer Coding for Kids, Carol Vorderman (DK, 2014). Bacaan pendamping untuk belajar coding dengan Scratch.
